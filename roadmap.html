// COCOMO II Intermediate (Step 4)
B = 0.91 + 0.01 × Σ(SF_i)    // scale exponent — 5 scale factors
E_nom = A × SizeB × EAF      // A=2.94

// LLM Adjustment (Steps 7–9)
A_i = 1 + (ordinal × 0.1)     // per-signal factor
E_final = E_nom × ∏ A_i        // product of all 5 factors

// Evaluation (Step 10)
MAE = mean(|actual − pred|)
RMSE = √mean((actual − pred)²)
MAPE = mean(|actual − pred| / actual) × 100

05 / REST API Endpoints

Projects
POST/api/v1/projectsCreate project. Validates domain, sizeKloc, teamSize. Accepts inputType: freetext | structured — exactly one of descriptionText or descriptionJson required.
GET/api/v1/projects?page&limitPaginated list of all projects.
GET/api/v1/projects/:idSingle project. 404 if not found.
PATCH/api/v1/projects/:idPartial update. Same validations as create.
DELETE/api/v1/projects/:idDelete. Cascades to estimations and signals. 204.
Estimations
POST/api/v1/estimationsTrigger full pipeline for { projectId }. Returns status: running.
GET/api/v1/estimations?projectId=List estimations for a project.
GET/api/v1/estimations/:idDetail with nested signals and adjustmentResult.
Evaluations
POST/api/v1/evaluationsRun evaluation. All projects must have actualEffortPm and completed estimation.
GET/api/v1/evaluationsList evaluation runs.
GET/api/v1/evaluations/:idResult with per-project rows.
Dataset
POST/api/v1/datasets/importMultipart CSV upload. Max 10 MB. Required columns: name, domain, size_kloc, team_size.

06 / LLM Integration Design

Prompt Structure
SYSTEM (cached prefix):
You are a software engineering expert.
Evaluate the project on exactly five signals.
Return ONLY valid JSON. No effort estimates.

Signal definitions: (5 defined)
Levels: very_low|low|medium|high|very_high

OUTPUT SCHEMA:
{"functional_complexity":
  {"level":"...","rationale":"..."},
 ... (5 total)}

USER:
Project description:
<normalized_text>
Retry Strategy
1
Call Claude → parse JSON → validate Zod schema
2
On failure → wait 1 s → retry
3
On failure → wait 2 s → retry
✕
After 3 failures → LlmUnavailableException (503)
Cost control: System prompt cached via Anthropic prefix caching. Input truncated to ~1500 tokens. ~$0.002 per run.

07 / Qualitative Signals & Ordinal Mapping

SignalWhat Claude EvaluatesHigh = more effort?Example High Case
functional_complexity Complexity of core business logic and user-facing features Yes Multi-tenant SaaS with complex billing rules
architectural_complexity System design — microservices, distributed state, CQRS Yes Event-sourced CQRS with 12 services
external_integrations Count and complexity of third-party APIs and data sources Yes 8 payment gateways, 3 ERPs, real-time feeds
requirement_stability How stable and well-defined are the requirements? No — High = stable = less effort Detailed spec with signed-off user stories
uncertainty Overall uncertainty in scope, tech choice, or team capability Yes New ML stack, first-time domain, unclear timeline
